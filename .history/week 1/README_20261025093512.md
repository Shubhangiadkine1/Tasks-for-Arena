# Personal Introduction Program

## About the Project
This is a beginner-friendly Python project that collects user information and displays a personalized welcome message.

## Features
- Collects name, age, city, hobby, favorite food, favorite subject, and future goal.
- Stores user information using variables.
- Uses a list to store interests.
- Displays age category.
- Calculates age for the next year.
- Shows a friendly welcome message.

## Concepts Used
- Variables and Data Types
- input() and print()
- Strings and f-strings
- Lists
- if-elif-else
- Basic Arithmetic

## How to Run
1. Install Python.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the following command:

```bash
python personal_intro.py
```

## Requirements
Python 3.x
